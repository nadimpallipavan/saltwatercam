# SaltWaterCam V1 React Starter

Responsive React + Vite starter for SaltWaterCam V1.

## Install
```bash
npm install
```

## Run locally
```bash
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

## Replace before launch
- Replace placeholder live stream in `src/components/LiveStream.jsx`
- Add real logo assets in `src/assets`
- Update SEO domain in `public/sitemap.xml` and `public/robots.txt`
- Deploy `dist/` to Vercel, Netlify, or any static host
